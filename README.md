# ChainEquity — Blockchain Enterprise Finance Concept

ChainEquity is an academic and collaborative enterprise-development project exploring how blockchain can support SME capital raising, transparent equity processes, and investor participation.

## Concept

The project investigates equity tokenisation, IPO and investment workflows, automated onboarding, investor access, and the design challenges involved in connecting traditional finance with decentralised infrastructure.

## Contribution

The project involved research, requirements analysis, solution design, and blockchain-oriented product thinking. The team produced an initial technical concept and prototype direction within the available MSc project timeframe.

This is a research/design prototype, not a live regulated investment platform.
